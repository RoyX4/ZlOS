# Project Evidence

These files record measured comparisons, merge events, and focused verification
work. They are dated evidence, not the current task queue.

- `MERGE-EVIDENCE.md` records the first multi-track landing.
- `MERGE-ROUND-2.md` records the second worktree/integration state.
- `integration/` contains the completed worktree and all-branch closure receipts.
- `status-audits/` contains dated project-state audits superseded as live queues.
- `POINTER-EVIDENCE.md` records the pointer diagnosis and its proof ceiling.
- `COMPARE-BOREDOS.md` is a measured peer comparison.
- `../shots/` contains intentionally curated visual evidence.

Read [`../PROJECT-STATUS.md`](../PROJECT-STATUS.md) before using an old receipt
as a current claim.
