The north star

A CPU-rendered desktop that looks intentional, not unfinished.

The screen above is the target for zlOS — the look once the windowing system, soft shadows, and anti-aliased text land. It is not a Windows clone. It is what TempleOS would be if it cared about visual polish and had a true-colour framebuffer to work with.

Everything above obeys the same hardware limits the kernel does: no GPU, no floating point, a single linear framebuffer drawn one pixel at a time by the CPU. That constraint is a design language, not a handicap — vertical gradients only, a fixed palette, tight low-spread shadows, small corner radii, alpha blends but no gaussian blur. Lean into it and the result reads as a deliberate aesthetic instead of a failed imitation.

Palette

One cool blue-slate world, one cyan accent, spent sparingly.

The whole system lives in a narrow band of desaturated blues so the single cyan accent — used only for focus, links, and live state — actually pops. Semantic greens/ambers/reds are separate from the accent and only ever mean status.

Typography

Monospace is the OS voice; the bitmap grid is the texture.

A console-rooted OS earns its monospace type honestly. The real win queued in the build is anti-aliased glyphs — greying the edges of the 8×16 font so text stops screaming 1990. Everything inside the screen is mono; this document you're reading is set in the system sans, so the OS and the writing about it stay visually distinct.

Window anatomy

Gradient title bar, cyan focus underline, a real drop shadow.

Each window is a gradient title bar (focused = brighter blue + a 2px cyan underline), a hairline black border, a 5px radius, and a soft shadow offset down-right. Depth comes entirely from that shadow and the border — the one cue a software compositor can afford. Unfocused windows drop the cyan and dim their bar so focus reads instantly.

Critical path

get_px — reading a pixel back — is the primitive everything visual depends on: soft shadows, anti-aliased text over the wallpaper, and a mouse cursor that doesn't smear. It ships first and must mirror the framebuffer byte order exactly, or every shadow comes out with red and blue swapped.
