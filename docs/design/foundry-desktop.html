What this is

A full desktop look, not a patch on lime

Branch secret/desktop-foundry. Worktree beside the repo. Nothing in kernel.zl, ui.c, or design.h was edited. Shipping look is still lime on grey, measured out of ds-reference.html. This file is the other direction.

Open the desktop (the screen above). Click the dock, Activities, close boxes. It is a mock of chrome and apps together, not a mood board of buttons.

Direction

Foundry

Iron field. Bone type. One copper accent for focus and the live mark. Four depths: wallpaper, idle window, focused window, overlay. Motion only on open, press, hover. Wallpaper is a cached ember, because the compositor cannot afford a live blur behind a moving window.

Why the current desktop feels like boxes

Worst thingWhyWhat Foundry does
Empty slabsApps are rectangles with a title and a voidSide rails, tabs, columns, a path, a status line
Bottom bar as a wallFull-width dock is the biggest rectangle on screenFloating dock, wallpaper shows around it
Accent on everythingLime is identity, hover, ok, and decorationCopper is focus and the pip. Ok stays green. Close stays red

Radius stays in an 8-12px band. Title 32px. Island 32px. Type is IBM Plex Sans for chrome, IBM Plex Mono for paths, code, and numbers. Not Inter, not the lime, not VisionOS glass.

What can actually be painted

Rounded rects, alpha, a cached gradient plus grain, a 1px focus ring, floating island, floating dock, time-based open/close. All of that already exists in fb.c / wm.c / ui.c. This mock does not ask for live backdrop blur, vector fonts, or a light theme.

If you want this in the OS, that is a later pass on design.h and the shell. This branch is only the picture.
