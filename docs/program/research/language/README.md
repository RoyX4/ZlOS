# zl Language Plan Snapshots

These four files are read-only snapshots of the language repository's active
orientation and plans as inspected on 2026-08-25. They are retained here so the
zlOS clean-room program remains understandable without another checkout.

The language repository remains authoritative for later changes. A snapshot in
this folder is research input, not evidence that its plan is implemented.

- `HANDOFF.md` - current language implementation handoff.
- `MASTER_PLAN.md` - full language destination.
- `ROADMAP.md` - staged language delivery order.
- `ULTIMATE_PLAN.md` - higher-level language direction.
