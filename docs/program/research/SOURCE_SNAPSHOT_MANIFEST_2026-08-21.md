## Brook upstream submodule defect

Brook contains fourteen gitlinks. Only these two have entries and URLs in `.gitmodules`, and both are initialized:

- `vendor/uefi-headers`
- `src/third_party/fatfs`

The twelve `tools/netsurf-build/*` gitlinks below have no `.gitmodules` records or URLs, so Git cannot initialize them from this repository alone:

- `buildsystem`, `libcss`, `libdom`, `libhubbub`, `libnsbmp`, `libnsfb`
- `libnsgif`, `libnsutils`, `libparserutils`, `libsvgtiny`, `libwapcaplet`, `netsurf`

This is an upstream repository metadata defect, not a failed declared-submodule download. Brook's own source plus both correctly declared submodules are present. Any reproducible browser/tool build must supply a separately versioned dependency manifest rather than guessing URLs for unregistered gitlinks.
