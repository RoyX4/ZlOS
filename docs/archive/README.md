# Documentation Archive

This directory preserves useful history without presenting it as the live queue.

- `superseded/` contains plans replaced by newer status or roadmap documents.
- `prompts/` contains old execution and reconciliation briefs.
- `handoffs/` contains dated continuation notes whose work moved elsewhere.
- `backups/` contains backup copies retained only for recovery or comparison.

Moving a document here does not mark its feature work complete. Open work must
be carried into [`../PROJECT-STATUS.md`](../PROJECT-STATUS.md), the current
roadmap, or the program ledgers before the old document is archived.
