FOUR ZL CONSTRAINTS, each found by hitting it, each shaping how a body is written:

- string **literals** but no string **values**. `label == "-"` cannot work, so
  structural questions are answered by integers. This is also why `rail_name` /
  `rail_sub` / `rail_icon` / `rail_app` are four parallel tables rather than one
  table of records — not a preference, the language leaves no alternative.
- a call must fit on **one line**.
- **no floats** in the drawing path.
- a native gets **`Value[8]`**. `ui_grid_cell` takes ten arguments, so align,
  size and the mono face are packed into one word.
