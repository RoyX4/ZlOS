# learn/

Ten graded zl exercises. Each file has stubbed functions and `assert`s that
fail until you fill them in. Worked answers are in `solutions/` — write yours
first, then diff.

```bash
learn/check.sh              # run every exercise, show what's red
learn/check.sh 03           # just exercise 03
learn/check.sh 03 --sol     # the worked solution for 03
learn/check.sh "" --sol     # regression-check every solution
```

Run from the repo root — `import` resolves `stdlib/` relative to it.

Full guide, gotchas, and the VS Code loop: [../docs/LEARNING.md](../docs/LEARNING.md).
