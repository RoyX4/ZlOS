# Exercise Evidence

This directory contains curated outputs retained from specific QEMU, visual,
performance, and physical-debug sessions. New disposable runs still write to
the ignored `kernel/exercise-out/`; only evidence with a dated receipt belongs
here.

`2026-08-24/` is the lossless relocation of the 50 tracked files that formerly
occupied the ignored output directory. The move changes paths, not evidence
strength: the visual registry still classifies its BIOS/UEFI images as unbound
prior-QEMU screenshots, and the physical touchpad material keeps its own stated
hardware boundary.
