# zlOS license and provenance truth

The current build has no repository-evidenced public redistribution grant.
That is now a machine-readable fact in
[`../metadata/license-registry.json`](../metadata/license-registry.json), generated by
[`../tools/generators/gen-license-registry.py`](../tools/generators/gen-license-registry.py).

The registry joins all 121 exact source/build inputs from `build-identity.json`
to their hashes. It searches the repository for `LICENSE`, `COPYING` and
`NOTICE` variants. The current result is:

- zero declared license files;
- zero inputs with an established redistribution grant;
- authorship not inferred merely because a file is local;
- public release blocked.

This does not block private development or QEMU/physical testing. It blocks a
future release process from claiming the source, generated font/icon material,
firmware dependencies or packaged image can be redistributed until Zac chooses
a project license and every imported/generated asset or third-party component
has an explicit origin and compatible grant.

The landing gate checks that the gap remains recorded. The self-test plants a
missing input, invented grant, false release green and missing source identity.
The generator never writes a license or makes a legal decision.
