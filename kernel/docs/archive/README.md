# Kernel Documentation Archive

- `prompts/` contains old execution briefs.
- `audits/` contains dated session/task audits.
- `handoffs/` contains recovery notes superseded by newer receipts or status maps.
- `superseded/` contains old plans and catalogues whose useful history remains,
  but whose status or queue has a newer authority.

These files remain useful for provenance and failure history. They are not the
current kernel queue.
