THE ONE ORDERED COLD-START SEQUENCE\n\nEvery step: **what is written → what is waited on → timeout.** \"posting read\" = read the register back before the next delay or poll.\n\n### Phase A — survey firmware state (no writes)\n\n1. Map BAR0 uncached. Read and save: `DDI_BUF_CTL_A(0x64000)` → `saved_port_bits = val & ((1<<16)|(1<<4))`, `max_lanes = (val&BIT(4))?4:2`; `DDI_BUF_TRANS_A[0..9]` (20 dwords); `DISPIO_CR_TX_BMU_CR0(0x6C00C)`; `CDCLK_CTL(0x46000)`; `DPLL_CTRL1/2`, `DPLL_STATUS`; `PP_STATUS/PP_CONTROL/PP_ON_DELAYS/PP_OFF_DELAYS`; `TRANSCONF(0x7F008)`; `TRANS_DDI_FUNC_CTL(0x6F400)`; `EDP_PSR_CTL(0x6F800)`; `PLANE_CTL/SURF`. No wait.\n   *This is the single highest-value step in the whole plan: the firmware's DDI_BUF_TRANS values encode the OEM's low-vswing decision, which is otherwise only in VBT and not discoverable from any register.*\n2. `last_power_off_time = monotonic_now()` (unknown history ⇒ owe a full T12). No wait.\n\n### Phase B — display core\n\n3. Write `DC_STATE_EN(0x45504) = 0`. **Wait:** read back until the value sticks for 6 consecutive reads; rewrite up to 100 times (DMC fights you). No wall-clock timeout.\n4. If `EDP_PSR_CTL(0x6F800)` b31 set → clear b31. **Wait:** `EDP_PSR_STATUS(0x6F840)[31:29] == 0`. **Timeout: 50 ms** (not documented; see §6).\n5. **Wait:** `SKL_FUSE_STATUS(0x42000)` b27 (PG0 dist) == 1. **Timeout 1 ms.**\n6. `HSW_PWR_WELL_CTL2(0x45404) |= BIT(29)` (PW1 REQ). **Wait:** b28 == 1, **timeout 1 ms**; then `FUSE_STATUS` b26 == 1, **timeout 1 ms.**\n7. `HSW_PWR_WELL_CTL2 |= BIT(1)` (MISC_IO). **Wait:** b0 == 1, **timeout 1 ms.**\n8. DPLL0: if `DPLL_STATUS` b0 already 1 **and** `DPLL_CTRL1[3:1]` already the wanted rate → **do nothing** (see hazard H6). Else write `DPLL_CTRL1` (rate at 3:1, OVERRIDE b0, HDMI_MODE/SSC clear), then `LCPLL1_CTL(0x46010) |= BIT(31)`. **Wait:** `LCPLL1_CTL` b30 **and** `DPLL_STATUS` b0 == 1. **Timeout 5 ms.**\n9. Read `CDCLK_CTL(0x46000)`. Require `cdclk_kHz >= pixel_rate_kHz` (241,699 kHz here — any of 337.5/450/540/675 MHz suffices). If sufficient, **leave it alone.** No wait.\n10. `DBUF_CTL_S0(0x45008) |= BIT(31)`; posting read; **fixed delay 10 µs**; check b30 == 1 (single check, not a poll loop).\n\n### Phase C — panel power and VDD\n\n11. Compute the five PPS delays = `max(current register value, VBT value)`, else the eDP-spec ceiling (up 210 ms, BL-on 50, BL-off 50, down 500, cycle 510). Round T12 up to a 100 ms multiple. No wait.\n12. Write `PP_ON_DELAYS(0xC7208) = (up_100us<<16)|bl_on_100us`; `PP_OFF_DELAYS(0xC720C) = (down_100us<<16)|bl_off_100us`; **RMW** `PP_CONTROL(0xC7204)`: bits 8:4 = `ceil(T12_ms/100)+1`, ensure b1 set. Posting read. No wait. **Must precede any PANEL_POWER_ON assertion.**\n13. `wait_panel_power_cycle()`: sleep `max(0, T12 - (now - last_power_off_time))`, then poll `PP_STATUS` until `(v & 0xB800000F) == 0`. **Poll 10 ms, timeout 5000 ms.** Both halves required — the software wait covers the VDD-dropped-last case where the HW sequencer never ran.\n14. If `PP_STATUS` b31 == 0: **RMW** `PP_CONTROL |= BIT(3)` (FORCE_VDD); posting read; **sleep T3 (200 ms)** — flat sleep, no status bit reports VDD-ready separately. If b31 == 1, VDD is already up; skip both.\n\n### Phase D — AUX and sink discovery (VDD-only is sufficient)\n\n15. AUX per-transaction preamble: `DC_STATE_EN = 0` (already done, step 3). Acquire `DDI_AUX_MUTEX(0x6402C)`: write `BIT(31)`, then read; `(v & BIT(30)) == 0` ⇒ acquired; else sleep 500 µs and re-read. **Timeout: not specified by PRM — use 10 ms, then fail loudly.** Skippable only if PSR1, PSR2 and GTC are all provably off; take it unconditionally (2 writes + 1 read).\n16. Drain: read `DDI_AUX_CTL(0x64010)`; if b31 set, sleep 1 ms, retry up to 3× total; still busy ⇒ EBUSY.\n17. Write `DATA1..n` (`ceil(send_bytes/4)` DWords, MSbyte-first). Then one 32-bit write to `DDI_AUX_CTL` = `BIT(31)|BIT(30)|BIT(29)|BIT(28)|(3<<26)|BIT(25)|(send_bytes<<20)|(17<<5)|31`. The three W1C bits clear stale status in the same write that starts the transaction. **Wait:** b31 == 0, poll 10 µs, **timeout 10 ms.**\n18. Status decode, in this order: `b25 RECEIVE_ERROR` → clear, sleep **400 µs**, retry (≤5 HW attempts), **do not read DATA**; `b28 TIMEOUT` → clear, retry immediately (the 1600 µs already exceeds 400 µs); `b30 DONE` clear → hardware anomaly, abort. Then `recv_bytes = (status>>20)&0x1F` (0 or >20 ⇒ illegal, retry). Read `ceil(recv_bytes/4)` DWords. Clear flags with `status | BIT(30)|BIT(28)|BIT(25)` — **b31 is 0 in `status`; never OR it in.** Release mutex: `DDI_AUX_MUTEX = BIT(31)|BIT(30)`.\n19. Reply nibble = `rx[0]>>4`: bits 1:0 native (00 ACK, 01 NACK, 10 DEFER), bits 3:2 I2C. **A DEFER looks like a perfect success in `DDI_AUX_CTL`** — DONE=1, no errors, Message Size=1. Protocol retry: **native DEFER → up to 32 attempts at 500 µs**; I2C DEFER → `max(7, bus-derived)` plus up to 7 extra, reissue writes as `I2C Write-Status-Update (0x2)`; **NACK → do not retry.**\n20. Read DPCD `0x00000..0x0000E` (15 B, one transaction). `dpcd[0] == 0` ⇒ fail, do not proceed.\n21. If `dpcd[0x0E] & 0x80`: read `0x02200..0x0220E`; keep the base copy if `dpcd[0] > ext[0]` or the blocks are identical; otherwise replace the whole 15-byte cap block.\n22. Write DPCD `0x00600 = 0x01` (D0). Up to 3 attempts, 1 ms apart. Skip if `dpcd[0] < 0x11`; treat failure as fatal if `edp_dpcd[1] & 0x80` (SET_POWER_CAP).\n23. Read DPCD `0x00700..0x00704` (5 B) **unconditionally** — do not gate on `0x0000D` b3; buggy panels clear it.\n24. If `edp_dpcd[0] >= 0x03` **OR** `dpcd[0] >= 0x13`: read `0x00010..0x0001F` (16 B). Parse 8 LE u16, stop at first zero, `rate_kHz = val * 200`. ≥1 entry ⇒ **Method B (LINK_RATE_SET)**; else **Method A (LINK_BW_SET)**.\n25. Read EDID over **I2C-over-AUX, slave 0x50** (command nibble 0x1/0x5 with MOT; address `0x00050`). **Not GMBUS** — see §5.\n26. Choose lanes/rate: `pixel_clock_Hz * bpp <= rate_bps * lanes * 8/10`. For 2720×1481@60 (241.7 MHz) at 24 bpp ⇒ 5.80 Gbps needed; 4×HBR = 8.64 Gbps usable ✓, 2×HBR = 4.32 ✗, 4×RBR = 5.18 ✗. **4 lanes @ HBR is the only working point; there is no valid fallback below it at 24 bpp.**\n\n### Phase E — full panel power\n\n27. If `PP_STATUS` b31 == 0: `wait_panel_power_cycle()` (step 13 again), then **RMW** `PP_CONTROL |= BIT(0)|BIT(1)`; posting read. **Wait:** `PP_STATUS & 0xB000000F == 0x80000008`. **Poll 10 ms, timeout 5000 ms.** Record `last_power_on = now`. Hardware runs T3 during this poll, so no extra sleep.\n\n### Phase F — port bring-up\n\n28. `HSW_PWR_WELL_CTL2 |= BIT(3)` (DDI_A_E IO REQ). **Wait:** b2 == 1. **PRM: 20 µs; budget 1 ms.**\n29. `DPLL_CTRL2(0x6C05C)`: clear b15 (DDI A CLK_OFF) and bits 2:1, set CLK_SEL = 0 (DPLL0), set b0 (SEL_OVERRIDE). No wait.\n30. **Mandatory if firmware left the port up** (`DDI_BUF_CTL_A` b31 set): clear `DDI_BUF_CTL_A` b31 → clear `DP_TP_CTL_A` b31 (**do not** go through Idle when disabling) → **wait** `DDI_BUF_CTL_A` b7 == 1, **expect 8 µs, budget 1 ms.** PRM: retraining requires disable-then-re-enable with pattern 1.\n31. Write `DDI_BUF_TRANS_A` entries: `0x64E00+i*8` = LO, `+4` = HI, for i = 0..9 (eDP low-vswing) or 0..8 (DP table). LO before HI. No wait. **Must complete before DDI_BUF_CTL enable.**\n32. **RMW** `DISPIO_CR_TX_BMU_CR0(0x6C00C)`: clear `BALANCE_LEG_MASK(A)=7<<8` and `BALANCE_LEG_DISABLE(A)=1<<23`; if I_boost != 0 set `iboost<<8`, else set `BIT(23)`. **If DDI_A_4_LANES: repeat for port index 4** (mask `7<<20`, disable bit `1<<27`). For the low-vswing eDP table I_boost is 0 for every entry ⇒ set BIT(23). Never touch bits 31:28 or 7:0. No wait.\n33. Build `DP_reg = saved_port_bits | ((lanes-1)<<1) | (0<<24)` (level 0). Write `DP_TP_CTL_A(0x64040) = BIT(31) | (0<<27) | (0<<8 /*TPS1*/) | (enh_frame ? BIT(18) : 0)`; posting read. **DP_TP_CTL must be enabled with TPS1 already selected, before DDI_BUF_CTL.**\n34. Write `DDI_BUF_CTL_A = DP_reg` (b31 clear); posting read. Then `DDI_BUF_CTL_A = DP_reg | BIT(31)`; posting read.\n35. **Blind wait ≥ 518 µs (use 600 µs).** No status bit exists on Gen9 — the `!IDLE` poll is gated to DISPLAY_VER ≥ 10. Do not substitute a poll.\n\n### Phase G — link training\n\n36. Write DPCD `0x00107..0x00108` as **one 2-byte burst**: `{0x00, 0x01}` (downspread off, ANSI 8b/10b). **Must precede step 37.**\n37. Method A: **one 2-byte burst** at `0x00100` = `{bw_code, lanes | (enh?0x80:0)}`. Method B: `0x00101 = lanes|(enh?0x80:0)`, then `0x00115 = table_index`; **never write 0x00100.** (Table index is a DPCD index — unrelated to the DPLL rate index; search the table for the target rate.)\n38. CR delay: `rev >= 0x14 → 100 µs`; else `interval==0 → 100 µs`; else `interval*4000 µs`.\n39. `train_set[*] = 0x00`. RMW `DDI_BUF_CTL_A[27:24] = 0`; posting read. `DP_TP_CTL[10:8] = 000b`. Write DPCD `0x00102`, **(1+lanes) bytes, one transaction**: `[0]=0x21` (TPS1|SCRAMBLING_DISABLE), `[1..n]=train_set`.\n40. CR loop, `max_cr_tries = (rev>=0x14) ? 10 : 80`, `voltage_tries = 1`:\n    a. **sleep(delay) FIRST**, then read DPCD `0x00202..0x00207` (**6 bytes, one transaction**).\n    b. All active lanes CR_DONE ⇒ pass. (`INTERLANE_ALIGN_DONE` is **not** checked here.)\n    c. `voltage_tries == 5` ⇒ fail. `max_vswing_reached` ⇒ fail.\n    d. `v = max(vs_req over lanes)`, `p = max(pe_req over lanes)`. Clamp **in this order**: `p >= 3 → p = 3 | MAX_PE_REACHED`; `v = min(v, dp_voltage_max(p))` where p=0→3, 1→2, 2→1, 3→0; `v >= table_max → v = table_max | MAX_SWING_REACHED`. Same byte to all lanes (Gen9 has no per-lane levels).\n    e. RMW `DDI_BUF_CTL_A[27:24] = index(v,p)`, port stays enabled, posting read. Re-evaluate I_boost for the new entry if the table uses it. **No 518 µs wait on a level change.**\n    f. Write DPCD `0x00103`, **lanes bytes only** — do **not** rewrite `0x00102` (it restarts the sink's training timer).\n    g. `voltage_tries++` iff the sink's `0x206/0x207` bytes are unchanged vs the previous iteration; else reset to 1.\n    h. `max_vswing_reached` = every active lane has `MAX_SWING_REACHED` **and** `v+p == 3`.\n41. EQ delay: `interval==0 → 400 µs`; else `interval*4000 µs`. **Note the asymmetry: 100 µs for CR, 400 µs for EQ at interval 0, and the rev≥1.4 \"force 100 µs\" applies to CR only.**\n42. Pattern = TPS3 if `dpcd[0x02] & 0x40` else TPS2 (source TPS3 is always available on gen9; TPS4 never is). `DP_TP_CTL[10:8] = 100b` (TPS3) or `001b` (TPS2). Write DPCD `0x00102`, (1+lanes) bytes: `[0] = 0x23` or `0x22`, `[1..n] = train_set` **carried over from CR, not reset**.\n43. EQ loop, **exactly 5 iterations**: sleep(delay); read 6 bytes; `!clock_recovery_ok` ⇒ abort (checked first, every iteration); `INTERLANE_ALIGN_DONE && every active lane == 0x07` ⇒ pass; else recompute, RMW `DDI_BUF_CTL[27:24]`, write DPCD `0x00103` (lanes bytes). No vswing-repeat or max-swing bail-out here.\n44. Stop: write DPCD `0x00102 = 0x00` — **1 byte, no lane bytes appended**. Then `DP_TP_CTL[10:8] = 010b` (Idle) — **do not poll 0x64044**. Then `DP_TP_CTL[10:8] = 011b` (Normal). All three are required, in that order.\n\n### Phase H — transcoder and pipe\n\n45. `PIPE_DATA_M1(0x6F030) = (63<<25) | data_m`; `PIPE_DATA_N1(0x6F034) = data_n`; `PIPE_LINK_M1(0x6F040)`, `PIPE_LINK_N1(0x6F044)`; M2/N2 = 0. `TU = 64` ⇒ field 63. `data ratio = bpp*pixel_clock : link_clock*lanes*8`, `link ratio = pixel_clock : link_clock`; N rounded up to a power of two, capped 0x800000 (data) / 0x80000 (link), then reduced; both fields 24 bits.\n46. `TRANS_MSA_MISC(0x6F410) = BIT(0) | (1<<5)` (sync clock, 8 bpc).\n47. `TRANS_VSYNCSHIFT(0x6F028) = 0`; then `0x6F000/04/08/0C/10/14` = HTOTAL/HBLANK/HSYNC/VTOTAL/VBLANK/VSYNC, each `((end-1)<<16)|(start-1)`. **Do not write TRANS_MULT.**\n48. `PIPE_SRCSZ(0x6001C) = ((2560-1)<<16) | (1440-1)`.\n49. `PIPE_MISC(0x70030) = 0` (8 bpc, no dither). **bpc does NOT go in TRANSCONF on gen9.**\n50. `CHICKEN_TRANS_EDP(0x420CC)[28:27] = 0` (reset value; no-op on a cold box).\n51. Scaler off: `PS_CTRL_1_A(0x68180) = 0`, `PS_CTRL_2_A(0x68280) = 0`.\n52. `WM_LINETIME(0x45270) = min(0x1FF, ceil(htotal*8000 / pixel_rate_kHz))` → 90.\n53. Safe single-pipe values:\n    `CUR_BUF_CFG(0x7017C) = (7<<16)|0`; `CUR_WM(0)(0x70140) = BIT(31)|8`; `PLANE_BUF_CFG(0x7027C) = (891<<16)|8`; `PLANE_WM(0)(0x70240) = BIT(31)|256`; all other levels and both `*_WM_TRANS` = 0. (Real requirement is ~21 blocks; 256 is a large-but-legal margin, and 256 < 884 allocated.)\n54. `TRANS_DDI_FUNC_CTL(0x6F400)` — **single 32-bit write, not RMW**: `BIT(31)|(2<<24)|(0<<20)|pvsync|phsync|(0<<12)|((lanes-1)<<1)` = **0x82000006** + sync bits.\n55. `TRANSCONF(0x7F008) |= BIT(31)`; posting read. **Wait:** nothing mandatory. Optional sanity: read `PIPEDSL(0x70000)` twice ~100 µs apart and confirm bits 19:0 changed.\n56. Plane, in this order: `STRIDE(0x70188)`, `POS(0x7018C)`, `SIZE(0x70190)`, `KEYVAL/KEYMSK/KEYMAX = 0`, `OFFSET(0x701A4)`, `AUX_DIST/AUX_OFFSET = 0`, then `PLANE_CTL(0x70180)`, then **`PLANE_SURF(0x7019C)` LAST — this arms everything.** For 2560×1440 XRGB8888 linear: `PLANE_CTL = 0x84002000`, `PLANE_STRIDE = 160` (10240/64), `PLANE_SIZE = 0x059F09FF`. Verify with `PLANE_SURFLIVE(0x701AC)`.\n57. Clear `GEN8_DE_PIPE_IIR(0x44408)` b31 and start watching it.\n58. Backlight: write `BXT_BLC_PWM_FREQ(0xC8254)` then `BXT_BLC_PWM_DUTY(0xC8258)` then `BXT_BLC_PWM_CTL(0xC8250) |= BIT(31)` (frequency and duty **before** enable). Wait `backlight_on_delay` measured from `last_power_on` (1 ms here). **RMW** `PP_CONTROL |= BIT(2)`; posting read.\n\n---\n\n# 3. TEARDOWN SEQUENCE\n\n1. **RMW** `PP_CONTROL &= ~BIT(2)` (BLC off); posting read. Stamp `last_backlight_off`.\n2. **Sleep `backlight_off_delay` — 260 ms on this panel.** Not optional.\n3. `BXT_BLC_PWM_CTL(0xC8250) &= ~BIT(31)`.\n4. If `EDP_PSR_CTL(0x6F800)` b31 set → clear; wait `EDP_PSR_STATUS(0x6F840)[31:29] == 0`, timeout 50 ms.\n5. Plane off: write the \"disabled\" watermarks first, then `PLANE_CTL(0x70180) = 0`, then `PLANE_SURF(0x7019C) = 0` (the CTL=0 write is armed by the SURF write). Same for cursor: `CUR_CTL = 0` then `CUR_BASE = 0`. **Everything on the pipe must be off before step 7.**\n6. Stop consuming vblanks / disable vblank interrupts.\n7. `TRANSCONF(0x7F008) &= ~BIT(31)`. **Wait:** b30 (STATE, read-only) == 0. **Timeout 100 ms.** Polling b31 succeeds instantly and tells you nothing.\n8. `TRANS_DDI_FUNC_CTL(0x6F400)`: clear b31, then clear port-sync (19:18, b15), then clear 30:28 and 26:24. (Writing 0 outright is also fine on gen9.)\n9. `DDI_BUF_CTL_A(0x64000) &= ~BIT(31)`.\n10. `DP_TP_CTL_A(0x64040) &= ~BIT(31)` — **do not** route through Idle on the disable path.\n11. **Wait:** `DDI_BUF_CTL_A` b7 == 1. Expect 8 µs, budget 1 ms. (Order matters: the wait comes after the DP_TP_CTL disable, not between 9 and 10.)\n12. `TRANS_CLK_SEL` — skipped for EDP.\n13. `DPLL_CTRL2(0x6C05C) |= BIT(15)` (DDI A CLK_OFF).\n14. Panel off: **RMW** `PP_CONTROL |= BIT(3)` (force VDD on **first** — panels misbehave otherwise); then a single **RMW** clearing `BIT(0)|BIT(1)|BIT(2)|BIT(3)` together; posting read. **Wait:** `PP_STATUS & 0xB0000000 == 0`, poll 10 ms, **timeout 5000 ms.** Then **stamp `last_power_off_time = now`** — the T12 epoch. Also stamp it in any path where VDD is dropped while `PANEL_POWER_ON` was already 0.\n15. Drop the AUX power-domain reference.\n16. `HSW_PWR_WELL_CTL2 &= ~BIT(3)` (DDI A/E IO). Poll STATE clear, 1 ms; a stuck \"forced on\" is informational, not an error (DMC/BIOS may hold it).\n17. DPLL0: **do nothing.** It is always-on and feeds CDCLK.\n18. HAZARDS\n\n## 4.1 Can damage hardware\n\n| H | Hazard | Why |\n|---|---|---|\n| H1 | **Violating T12 (500 ms) before re-applying panel power or re-asserting FORCE_VDD.** The 1→0→1 transition of `PP_CONTROL` b3 is itself subject to T12. | Panel rails have not discharged; the TCON can latch into an undefined state. Several panel datasheets state this as \"may cause damage\", not \"artifacts\". PRM makes it a hard restriction in three places. |\n| H2 | **Driving AUX, the main link, PWM or BL_EN into an unpowered panel.** | The sink's AUX receiver is powered from VDD. With VDD off you are driving AUX± into unpowered input pins; current flows through the TCON's ESD/body diodes. This is an absolute-maximum-rating violation (Vin ≤ VDD + 0.3 V), not a timing preference. Assert an equivalent of i915's check: WARN if neither `PP_STATUS` b31 nor `PP_CONTROL` b3 is set before any AUX transaction. |\n| H3 | **Delay registers reset to 0x00000000 on soft reset.** A sequencer with T3=T9=T10=T12=0 reports ON instantly, lets you drive AUX before the sink is up, and yanks VDD with video still live. | Program Phase C step 12 **before** any PANEL_POWER_ON assertion, on every driver entry, including takeover from firmware. |\n| H4 | **Clearing `PP_CONTROL` b1 (Power Down on Reset).** | With it clear, any reset drops VDD instantly under live video instead of running the ordered T9/T10 sequence. Measured as 1 on this box; keep it set. |\n| H5 | **Skipping T9 (260 ms here) on the disable path.** | Video stops while the backlight is still lit: visible garbage, and a current transient in the LED driver on some panels. |\n\n## 4.2 Waits that must not be skipped or replaced with a poll\n\n| Wait | Value | Note |\n|---|---|---|\n| **≥ 518 µs after `DDI_BUF_CTL` b31 0→1** | 600 µs blind | **No status bit on Gen9.** The `!IDLE` poll is DISPLAY_VER ≥ 10 only. Not needed on a vswing-level change, only on the 0→1 transition. |\n| **T3 after FORCE_VDD when the panel was off** | 200 ms flat sleep | No separate VDD-ready status. |\n| **T12 before panel power / VDD re-assert** | 500 ms software wait **plus** the `PP_STATUS` b27 poll | Neither half is redundant — see §H1 and the VDD-dropped-last case. |\n| **Sleep BEFORE the first link-status read**, both in CR and EQ | 100 µs / 400 µs (or `interval*4000`) | Reading immediately after writing `TRAINING_PATTERN_SET` returns stale bits and \"fails\" a healthy link. |\n| **400 µs after an AUX RECEIVE_ERROR** | DP CTS 4.2.1.1/4.2.1.2 | Not needed after a hardware TIMEOUT (1600 µs already exceeds it). |\n| **`TRANSCONF` b30 == 0 on disable** | timeout 100 ms | The next steps kill clocks the pipe is still using. |\n| **`DDI_BUF_CTL` b7 == 1 on disable** | expect 8 µs, budget 1 ms | 8 µs as a hard failure is spec-accurate and field-inaccurate. |\n| **DPCD `0x00600` D0 → sink ready** | up to 1 ms, 3 retries | |\n\n## 4.3 Wrong value → silent black screen, no error anywhere\n\n1. **`TRANSCONF` at 0x6F008 instead of 0x7F008** — you write a nonsense hsync and never see a picture. (C1)\n2. **`PIPE_SRCSZ` at 0x6F01C instead of 0x6001C** — pipe-indexed register written into the transcoder block. (C2)\n3. **`PLANE_SURF` not written** — nothing you wrote to CTL/SIZE/STRIDE/POS takes effect. Looks exactly like a dead pipe. Read `PLANE_SURFLIVE(0x701AC)` to see what HW is actually scanning.\n4. **`PLANE_SURF` holding a physical rather than a GGTT address**, or GGTT PTEs not mapped (BAR0+8 MB, 64-bit entries, b0 = present). Black, zero diagnostics.\n5. **`DC_STATE_EN != 0` when touching AUX A.** `DDI_AUX_CTL_A` is in PG1; PG1 gates on DC5/DC6. Reads return zeros, writes go nowhere, no error bit. This is the #1 cause of \"AUX works on some boots\".\n6. **`DDI_AUX_CTL[27:26] = 00b`** (the reset default) — the forbidden 400 µs setting.\n7. **Treating an AUX DEFER as success.** DONE=1, no error bits, Message Size=1 — you get a zero-length \"successful\" read and garbage data.\n8. **Enhanced framing mismatch** between `DP_TP_CTL` b18 and DPCD `0x00101` b7 — a stable link showing garbage. `DP_TP_CTL` b18 cannot be changed while the DDI is enabled, so it must be decided before port enable.\n9. **`INTERLANE_ALIGN_DONE` not checked in EQ** (or wrongly checked in CR) — \"training passed\", picture is garbage / training never converges.\n10. **DPLL rate index ≠ DPCD `LINK_RATE_SET` index.** Different index spaces. In a typical table, DPCD index 1 is 2.16 Gbps, not 2.7. Always linear-search the table.\n11. **`vswing + preemph > 3`** — a legal-looking DPCD write producing an untrainable link.\n12. **bpc programmed in `TRANSCONF[7:5]`** (ctg-ivb only) instead of `PIPE_MISC(0x70030)`.\n13. **Watermark too small, or `blocks >= plane DDB allocation`** — FIFO underrun, tearing bands, and on eDP often a link that never recovers. `GEN8_DE_PIPE_IIR(0x44408)` b31 is your only telltale; an underrun appearing seconds after a \"successful\" modeset means marginal watermarks.\n14. **Overlapping `*_BUF_CFG` ranges, or any index > 891.**\n15. **`PLANE_CTL` tiling value 5** = Yf on gen9, Tile4 on gen12+. Cargo-culting a Tile4 driver programs a tiling the hardware reads differently.\n16. **Stride not a multiple of 64 (linear) / 512 (X-tiled)** — the register holds `bytes/unit` and the division is unchecked.\n17. **PSR left enabled by firmware** — fights every plane update and issues its own fast-wake AUX transactions on the same channel behind your back.\n18. **Writing `DDI_AUX_CTL` status-clear with b31 set** — launches a second, unintended transaction with whatever is stale in the DATA registers.\n19. **`DDI_BUF_TRANS` programmed after `DDI_BUF_CTL` enable**, or `DDI_A_4_LANES`/Port Reversal overwritten (both are boot-time straps; read once and OR into every write).\n20. **Changing rate or lane count without a full port disable/re-enable.** PRM: disable port → (re-)program PLL → re-enable and re-train. `DDI_BUF_CTL[3:1]` and `DP_TP_CTL[18]` must not change while the DDI is enabled.\n\n---\n\n# 5.
