# Machine-Readable Receipts

This directory contains tracked JSON receipts and retained recovery archives
consumed by `kernel/metadata/` and its generators. They record exact measured
inputs or runs; they are not prose status pages and their presence does not
promote adjacent features to complete.

Narrative interpretation belongs in `../evidence/` or a dated document in
`kernel/docs/`. Keep receipt paths stable unless every registry, generator, and
documentation reference moves atomically.
