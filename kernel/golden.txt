========================================
  zl kernel
  no OS. no libc. no syscalls.
========================================

the serial driver below is written in zl:
inb/outb are builtins, the polling is zl.

press h for help, q to halt.

zl> 

  h        this help
  f <n>    fib(n)
  s <n>    sum of squares to n
  m        read a byte back from VGA memory
  c        clear the screen
  q        halt the machine

zl> 
2
0

6765

zl>

0

zl>
